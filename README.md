# CArT/oneAPI Knowledge Base

Repositório central para documentação, experiências e resolução de problemas técnicos relacionados ao ecossistema **Intel oneAPI** e computação heterogênea no **CArT (PUC Minas)**.

Este espaço não é focado em um projeto de código específico, mas sim em centralizar o conhecimento técnico para acelerar o desenvolvimento de aplicações de alto desempenho da equipe.

---

## 🎯 Objetivo

Servir como uma base de consulta viva e colaborativa, evitando a redundância de esforços na resolução de bugs e configurações de ambiente.

## 🤝 Como Colaborar

A colaboração é essencial para manter esta base de conhecimento atualizada. Utilize os canais abaixo conforme a sua necessidade:

### 1. Documentar Soluções (Problemas Resolvidos)

Se você encontrou um erro, obstáculo ou comportamento inesperado e conseguiu resolvê-lo, registre a solução no arquivo abaixo:

* **[Problemas Enfrentados e Soluções](https://www.google.com/search?q=./problemas_enfrentados.md)**

### 2. Relatar Dificuldades (Problemas em Aberto)

Caso esteja enfrentando um problema técnico ainda não resolvido ou queira debater uma implementação específica, abra uma sinalização em nosso painel:

* **[Abrir uma Issue](https://www.google.com/search?q=https://github.com/cart-pucminas/oneAPI/issues)**

### 3. Melhorias na Documentação

Para novos guias, tutoriais ou correções de informações gerais, contribua diretamente via **Pull Request**.
